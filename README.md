# Личный Telegram-ассистент

Бот помогает пройти путь от списка мыслей до выполненного дела: выгрузить задачи, выбрать главное, найти посильный следующий шаг, открыть нужный материал и начать фокус-сессию. Версия **2.0** объединяет дела, знания и напоминания. У каждого пользователя своё пространство. Часовой пояс по умолчанию — **Москва, Europe/Moscow**.

Направление развития и обзор аналогов: [PRODUCT_DIRECTION.md](PRODUCT_DIRECTION.md). В версии **2.1** добавлены точки продолжения дел и учебные карточки.

Версия **3.0** добавляет проекты, личную память и случаи. Подробный статус нового функционала и ограничения: [MEMORY_ROADMAP.md](MEMORY_ROADMAP.md).

Версия **3.1** добавляет распознавание вложений с проверкой перед сохранением: PDF с текстом, TXT/MD, изображения JPEG/PNG и короткие голосовые Ogg Opus. Инструкция и точные ограничения: [RECOGNITION.md](RECOGNITION.md).

Версия **3.2** переводит навигацию в одну обновляемую панель. Отправьте `/start`: меню, карточки и пошаговый ввод будут открываться в одном сообщении, длинные тексты — листаться кнопками. Файлы, уведомления и ответы ИИ остаются отдельными сообщениями. Подробности и следующий шаг к Mini App: [INTERFACE.md](INTERFACE.md).

## Что умеет

- Принимать список дел с предварительным просмотром, хранить выполненные дела и один текущий приоритет.
- Подбирать следующее дело под 5, 15, 25 или 50 свободных минут по заданным пользователем оценкам времени.
- Запускать фокус для конкретного дела; в уведомлении можно сразу отметить результат. Таймер и дела переживают перезапуск.
- Связывать дела с сохранёнными материалами и по отдельному подтверждению разбирать выбранный текст с ИИ.
- Сохранять точку продолжения перед паузой: сделанное и следующий шаг, без потери названия дела.
- Создавать личные учебные карточки из материалов и возвращать их для самопроверки по расписанию.
- Создавать разовые, ежедневные и еженедельные напоминания, откладывать их и отмечать выполненными.
- Сохранять ссылки, заметки и пересланные сообщения, а также документы, фотографии, голосовые сообщения, видео и аудио.
- Подбирать категории по ключевым словам, сохранять хештеги и искать по заголовку, тексту, тегам и исходной ссылке.
- Показывать библиотеку по категориям, избранное и случайный материал, к которому полезно вернуться.
- Организовывать рабочие материалы в собственные разделы с кнопками в меню «Работа рядом».
- Показывать план на сегодня и статистику, запускать фокус-сессию на 25 минут.
- Присылать ежедневную сводку, если включить её в настройках. По умолчанию она выключена.
- Выгружать сохранённые тексты и метаданные в JSON.
- Общаться с DeepSeek по кнопке «💬 Диалог с ИИ», с отдельной памятью для каждого пользователя, если оператор подключил Yandex AI Studio.

Любой человек может открыть бота по его имени или ссылке и отправить `/start` в личном чате: отдельное пространство создаётся автоматически, без привязки владельца и одобрения оператора. Групповые чаты намеренно не поддерживаются.

Для библиотеки и напоминаний платный AI-сервис не нужен: классификация основана на правилах. ИИ-диалог использует DeepSeek через платный API Yandex AI Studio. В карточке вложения есть «Распознать содержимое»: текст PDF и TXT/MD извлекается локально, фото и короткий голос — через платные Yandex OCR/SpeechKit после отдельного запуска. Сайты по ссылкам бот пока не открывает.

## Первый запуск в Windows и VS Code

Эти шаги выполняет оператор — человек, который запускает бот на своём компьютере или сервере. Понадобится Python **3.11 или новее**. Из настроек обязательно заполнить только `BOT_TOKEN`; остальные имеют значения по умолчанию.

1. В Telegram откройте официального **@BotFather**, отправьте `/newbot` и создайте бота. [Инструкция Telegram](https://core.telegram.org/bots/features#botfather).
2. Откройте эту папку в VS Code: **Файл → Открыть папку**. Встроенный терминал открывается через **Терминал → Создать терминал**.
3. В терминале, находясь в папке проекта, подготовьте окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   if (-not (Test-Path -LiteralPath .env)) { Copy-Item -LiteralPath .env.example -Destination .env }
   ```

   Если `.venv` уже подготовлена, повторно создавать её не нужно. При обновлении проекта установите зависимости из `requirements.txt`. Последняя команда создаёт `.env` только при его отсутствии и сохраняет существующие настройки.

4. Откройте **локальный** файл `.env` в VS Code и вставьте токен после `BOT_TOKEN=`. Если рабочий токен уже записан, оставьте его. Не отправляйте токен в чат и не публикуйте этот файл:

   ```dotenv
   BOT_TOKEN=сюда_токен_из_BotFather
   TIMEZONE=Europe/Moscow
   DATABASE_PATH=data/assistant.sqlite3
   ```

5. Запустите бота:

   ```powershell
   .\.venv\Scripts\python.exe -m assistant_bot
   ```

6. Откройте созданного бота в Telegram и отправьте `/start` — появится ваше главное меню. Поделитесь именем бота или ссылкой `https://t.me/имя_вашего_бота` с другими людьми: после `/start` у каждого будет собственное пространство. Им не нужны токен, файлы проекта или доступ к базе данных.

Если обновляете прежнюю версию для одного владельца, сохраните текущий `.env` и прежний `DATABASE_PATH`. `OWNER_ID` больше не используется: старую строку можно удалить, оставив токен и остальные настройки. Базу удалять или пересоздавать не нужно: записи сохраняют привязку к прежним Telegram ID, поэтому материалы прежнего владельца остаются только в его пространстве. Новые пользователи получают пустую библиотеку.

Для следующих запусков можно использовать `.\start.ps1`. Скрипт всегда запускает проект из его собственной папки и сам ничего не устанавливает. Если PowerShell не разрешает запуск скриптов, используйте команду `.\.venv\Scripts\python.exe -m assistant_bot` из папки проекта — менять системные настройки не требуется.

В VS Code также есть конфигурация **«Личный Telegram-ассистент»** для запуска через F5, если установлены расширения Python и Python Debugger. В один момент запускайте только один экземпляр бота.

## Как пользоваться

### Главное меню и ежедневный цикл

В главном меню шесть кнопок прямо под сообщением:

| | |
| --- | --- |
| 🧭 Сегодня | 📥 Разгрузить голову |
| 📚 Мои материалы | Работа рядом |
| 💬 Диалог с ИИ | ☰ Ещё |

Поиск, категории и избранное находятся в «Мои материалы». В «Ещё» — проекты, память, учёба, напоминания, настройки, статистика, случайный материал, экспорт и помощь. Старые команды и кнопки продолжают работать. `/start` переносит активную панель вниз чата; бот пытается удалить только её прежний отслеживаемый экземпляр. Старую историю сообщений до этого обновления бот автоматически не очищает.

**Разгрузить голову** (`/capture`): отправьте до 12 дел, каждое с новой строки, до 300 символов. Проверьте список и подтвердите сохранение. Все строки считаются делами; бот не пытается автоматически определить их смысл. Начальная оценка — 25 минут. Из карточки можно уточнить следующий шаг, изменить время, назначить одно главное дело, отметить выполненным или вернуть из завершённых.

**Сегодня** (`/plan`, `/today`): открытые дела, главное дело, текущая фокус-сессия и ближайшие напоминания. «Что сейчас?» выбирает одно дело, которое укладывается в выбранное время; приоритет учитывается первым. Это подбор по вашим оценкам, а не прогноз ИИ. Если подходящих дел нет, можно уточнить маленький следующий шаг и его длительность. Главное дело остаётся приоритетным до завершения или смены приоритета.

**Фокус** запускается из карточки дела на 5, 15, 25 или 50 минут после подтверждения. Одновременно у пользователя одна сессия. В конце бот присылает кнопки «Дело сделано» и «Продолжить / открыть дело». Завершение дела отменяет его ожидающий таймер. Остановка таймера сохраняет дело. Уведомления приходят, пока бот работает и подключён к Telegram; после перезапуска ожидающие таймеры продолжают обслуживаться. Если начать новую сессию, старый просроченный, ещё не доставленный таймер отменяется.

**Материал → дело**: кнопка «Сделать делом» есть в библиотеке и «Работа рядом». Назовите действие — ссылка на исходную карточку прикрепится автоматически. Удаление материала не удаляет дело, а его карточка объяснит, что источник недоступен.

**Разобрать с ИИ**: выбранный материал можно превратить в краткую суть, варианты применения и три следующих шага. Перед отправкой бот запросит подтверждение. В Yandex AI Studio передаются название, первые 2500 символов текста выбранного материала и недавняя история личного ИИ-диалога. Используется обычная квота ИИ-запросов; ответ появляется в личном диалоге. Файлы и страницы по ссылкам не читаются, предложенные ИИ действия автоматически не сохраняются. Пустое текстовое описание разобрать нельзя.

Уже включённая ежедневная сводка теперь содержит также до трёх открытых дел. Новые регулярные рассылки автоматически не включаются. Дела входят в личную статистику и JSON-экспорт версии 6. Черновики отменяются при переходе к другой функции; сохранённые дела и завершённые результаты остаются после перезапуска.

### Проекты и личная память

Откройте **«Ещё → Проекты и опыт»** или `/projects`. Создайте проект и цель. Из библиотеки или «Работа рядом» можно связать оригинальный материал с проектом и указать тип: наблюдение, инструкция, решение, идея, вопрос, результат или предположение. Проект хранит копию текста/подписи на момент связывания; изменение оригинала автоматически её не меняет.

В проекте есть мастер случая **«объект → симптомы → проверки → действия → результат»**. Результат можно дополнить позже. Для дела, созданного из случая, после первого завершения бот предлагает записать, что помогло. Причина не объявляется доказанной только потому, что действие предшествовало улучшению.

`/memory запрос` ищет сразу по библиотеке, рабочим материалам и проектным записям. Возвращает выдержки, даты, типы и кнопки источников. Пока это поиск по словам с простой обработкой окончаний, без понимания дат событий, синонимов и содержимого вложений.

Фразы **«Верни меня в проект выставки»** и **«У меня есть 20 минут»** работают из обычного режима и просмотра дел/проектов. Первая открывает контекст проекта, вторая подбирает дело по заданной оценке времени. Во время другого пошагового ввода или ИИ-диалога сохраняется текущий сценарий.

Кнопка **«Исправить»** у текстовой записи показывает изменения и сохраняет предыдущую версию в истории. **«Памятка»** позволяет скачать себе Markdown с целью и текущими записями проекта для редактирования перед передачей. Удаление записи/проекта подтверждается отдельно, удаляет их историю и сохраняет исходные материалы и дела. Полный личный JSON-экспорт имеет версию **5**.

### Продолжить после перерыва

Откройте дело → **«⏸ Сохранить место и сделать паузу»**. Напишите, на чём остановились (до 800 символов), затем следующий шаг (до 300). После подтверждения сохраняются обе записи и отменяется ожидающий фокус-таймер этого дела. Название дела не меняется; чужие таймеры не затрагиваются. Последняя точка для незавершённого дела показывается в «Сегодня», полная — в его карточке. Повторное сохранение обновляет заметку. Данные сохраняются после перезапуска.

### Учёба и повторение

Откройте **«Ещё → Учёба»** или `/study`. Создайте вопрос (до 300 символов), затем ответ (до 1000), проверьте и сохраните. Кнопка **«Создать учебную карточку»** в материале прикрепляет ссылку на источник из библиотеки или «Работа рядом». Удаление источника не удаляет сам вопрос и ответ. В «Мои карточки» доступны просмотр, исправление и удаление с подтверждением.

При повторении сначала виден только вопрос. Ответьте мысленно или сообщением — ответ пользователя не сохраняется и не оценивается автоматически. Нажмите «Показать ответ», сравните и выберите **«Помню»** или **«Трудно»**. После успешных повторений интервал составляет 1, 3, 7, 14, затем 30 дней. При затруднении — 10 минут со сбросом ступени. Исправленная карточка начинает расписание заново. Это простая фиксированная схема, а не прогноз памяти или алгоритм Anki.

Готовые карточки видны в «Сегодня», /study и уже включённой ежедневной сводке. Бот не включает дополнительные уведомления автоматически. Эти сценарии работают без вызовов ИИ; учебные карточки и точки продолжения входят в личный JSON-экспорт версии 6.

### Работа рядом

Кнопка **«Работа рядом»** в главном меню или команда `/work` открывает ваши рабочие разделы. Например, можно создать «Инструкции», «Шаблоны», «Полезные ссылки» — каждый раздел станет отдельной кнопкой.

1. Нажмите **«➕ Добавить что-то нужное» → «📁 Добавить раздел»**, напишите название (до 60 символов) и подтвердите создание.
2. Для сохранения материала выберите **«📝 Добавить информацию в раздел»**, затем нужный раздел. Внутри раздела также есть кнопка **«➕ Добавить информацию»**.
3. Пришлите текст, ссылку, пересланное сообщение или одно вложение с подписью. Поддерживаются документы, фото, голосовые, аудио, видео, анимации и видеосообщения. Затем задайте название до 100 символов и нажмите **«✅ Сохранить»** в предварительном просмотре.
4. После сохранения можно сразу **добавить ещё сюда**. Если разделов пока нет, бот сначала предложит создать первый и продолжит добавление материала.

Кнопка материала открывает его карточку; длинный текст можно листать по страницам, файл — получить кнопкой открытия. Материал можно переименовать, переместить в другой свой раздел или удалить. В **«⚙️ Управление разделом»** доступны переименование, перемещение раздела выше/ниже и удаление. Удаление раздела вместе с содержимым требует отдельного подтверждения.

Кнопки **«Назад»**, **«Отмена»** и команда `/cancel` помогают выйти из добавления. Переход к другой функции отменяет незавершённый черновик. В режиме «Работа рядом» сообщения не попадают автоматически в общую базу знаний: сохранение материала требует подтверждения. Черновики существуют до перезапуска, а сохранённые разделы и материалы остаются в базе.

У каждого пользователя свои разделы и материалы. Они входят в его `/export` и отдельно учитываются в `/stats`; `/users` показывает администратору только суммарное количество материалов из библиотеки и рабочих разделов. Поиск `/search` относится к базе знаний; рабочие материалы открываются через свои разделы.

### Напоминания

Нажмите кнопку создания напоминания и следуйте подсказке или отправьте команду:

```text
/remind через 10 минут купить хлеб
/remind завтра в 09:00 позвонить
/remind каждый день в 09:00 выпить воды
/remind каждую неделю в 10:00 план недели
```

Бот сначала покажет время и текст: нажмите **«✅ Создать»**, чтобы сохранить напоминание. До подтверждения оно не запланировано. В меню доступны список напоминаний и действия с ними. После уведомления можно отметить дело выполненным или отложить его. Для регулярного напоминания «Готово сегодня» сохраняет следующие повторы; отдельная кнопка останавливает их.

`/today` показывает ожидающие дела на сегодня и просроченные. Фокус-сессия предлагает напоминание через 25 минут; его тоже нужно подтвердить — удобно для работы или учёбы.

### Библиотека знаний

Просто отправьте боту текст, ссылку или файл. Например:

```text
https://docs.python.org/3/tutorial/ Учебник Python #учёба #python
```

```text
Идея для проекта: собрать полезные инструменты для работы #идеи #работа
```

Бот создаст карточку, предложит категорию и сохранит ваши теги. Карточку можно добавить в избранное, изменить или удалить. Формат редактирования:

```text
Заголовок | Категория | #тег #тег
```

Например:

```text
Учебник Python | Обучение | #python #учёба
```

Чтобы найти материал, нажмите поиск или отправьте:

```text
/search python
```

Поиск проверяет сохранённые текстовые поля целиком, включая заголовок, текст, теги и исходную ссылку. Текст внутри вложенных файлов в поиск не попадает. В библиотеке также доступны фильтр по категории и избранное. Случайная карточка помогает вспомнить ранее сохранённое.

| `/memory запрос` | Общий поиск по личной памяти |
| `/remind` | Создать напоминание |
| `/today` | Дела на сегодня |
| `/library` | Библиотека материалов |
| `/work` | Работа рядом: личные разделы и материалы |
| `/search слово` | Найти сохранённое |
| `/settings` | Часовой пояс и ежедневная сводка |
| `/stats` | Статистика |
| `/export` | Экспорт текстов и метаданных в JSON |
| `/cancel` | Отменить текущий ввод |
| `/id` | Показать свой Telegram ID |
| `/help` | Подсказки и форматы ввода |
| `/users` | Список пользователей — только для администратора |
| `/chat` | Начать или продолжить свой диалог с ИИ |
| `/newchat` | Очистить память ИИ-диалога после подтверждения |

Настройки у каждого пользователя свои. `TIMEZONE` в `.env` задаёт начальное значение, по умолчанию московское; далее каждый выбирает пояс через `/settings`. Смена часового пояса применяется к новым напоминаниям. Уже созданные сохраняют часовой пояс, с которым были записаны. Ежедневная сводка также включается и настраивается отдельно для каждого человека.

### Как смотреть пользователей

Оператор указывает свой числовой Telegram ID в локальном `.env`: `ADMIN_ID=ваш_числовой_ID`, затем перезапускает бота. Свой ID можно узнать командой `/id`. Если `ADMIN_ID` не заполнен, доступ к списку закрыт для всех. Эта настройка не ограничивает регистрацию: бот по-прежнему доступен любому человеку.

Администратор отправляет `/users` в личном чате с ботом. Команда показывает общее количество пользователей, их имена, @username (если есть), Telegram ID и количество сохранённых материалов. Список разбит на страницы по восемь человек; есть кнопки перехода и обновления. Команда появляется в меню только в чате администратора. Проверка доступа действует и при ручном вводе команды, и при нажатии кнопок.

Новые пользователи попадают в список после первого личного сообщения боту. При обновлении прежней версии список дополняется владельцами уже сохранённых материалов, напоминаний и настроек. У таких пользователей имя может быть неизвестно до следующего сообщения боту.

Список не раскрывает тексты, ссылки, файлы, напоминания или настройки других людей. Администратор через команды бота тоже открывает и экспортирует только собственные материалы.

### Диалог с ИИ

Нажмите **«💬 Диалог с ИИ»** или отправьте `/chat`. В этом режиме текст передаётся ИИ, а не сохраняется в библиотеку. `/cancel`, кнопка выхода или переход к другому разделу возвращают обычное управление. «Новый диалог» после подтверждения очищает только вашу память ИИ; сообщения в Telegram и библиотека остаются. История сохраняется после перезапуска, но вход в режим общения нужно повторить.

Приветствие короткое: **«GPT 6 Astra. Задай вопрос.»** GPT 6 Astra используется как название ассистента, фактически отвечает DeepSeek через Яндекс. Сведения о передаче данных, памяти и лимитах открываются кнопкой **«ℹ️ О диалоге»**.

Telegram разрешает [до 4096 символов текста в сообщении](https://core.telegram.org/bots/api#sendmessage). Бот заменяет сообщение «Готовлю ответ…» готовым ответом. Если ответ длиннее, его можно листать кнопками **«Назад / Далее» в том же сообщении**; текст между страницами не теряется. При расчёте размера учитываются эмодзи и HTML-экранирование. В памяти диалога сохраняется весь ответ, независимо от открытой страницы. Кнопки доступны только автору вопроса в исходном сообщении. После перезапуска бота, очистки диалога или вытеснения ответа из временного кеша кнопки старого ответа становятся недоступны; кеш ограничен 128 последними длинными ответами на весь бот.

Оператор добавляет в локальный `.env` следующие настройки и перезапускает бота:

```dotenv
YANDEX_API_KEY=секретное_значение_ключа_Яндекса
YANDEX_FOLDER_ID=идентификатор_каталога
YANDEX_MODEL=deepseek-v4-flash
AI_DAILY_LIMIT=20
AI_GLOBAL_DAILY_LIMIT=100
```

Ключ создаётся в [Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/). Нужно **секретное значение** ключа, а не его идентификатор. Folder ID можно скопировать рядом с названием каталога. Не отправляйте ключ боту или в переписку. Все пользователи бота используют API-аккаунт оператора; запросы оплачиваются по [тарифам Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing). Без ключа или Folder ID кнопка объяснит, что подключение ещё не настроено, а остальные функции продолжат работать. Строки `OPENAI_API_KEY` и `OPENAI_MODEL` не используются.

По умолчанию выбран [DeepSeek V4 Flash](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models). Полный адрес модели `gpt://<Folder ID>/deepseek-v4-flash` собирается автоматически. Запросы отправляются только в Yandex AI Studio; ключ OpenAI не требуется.

По умолчанию разрешены 20 попыток запросов на человека и 100 на весь бот за сутки UTC (сброс в 03:00 по Москве). Неудачные и отменённые попытки тоже учитываются. Квоты хранятся в базе, поэтому перезапуск или очистка диалога их не сбрасывают. Это лимиты числа запросов, а не гарантированный денежный бюджет. Одновременно обрабатывается один вопрос от каждого пользователя; ожидание ответа ИИ не занимает общую блокировку напоминаний и других пользователей.

Диалог поддерживает текст до 4000 символов за раз. В локальной базе хранятся последние 6 пар вопросов и ответов каждого человека. Для ответа передаются текущий вопрос и ограниченная часть только его истории (до 20 000 символов истории). Вложения и библиотека автоматически не передаются. ИИ не создаёт напоминания и не меняет записи — для действий используются обычные кнопки бота. ИИ-история не входит в `/export` и не видна через `/users`.

В Yandex AI Studio передаются только текущий вопрос и недавняя история этого пользователя. Используется Responses API с `store=false` и заголовком `x-data-logging-enabled: false`: сохранение ответов для продолжения через API и логирование для улучшения сервиса отключаются. Это не отключает все виды служебных логов и не меняет настройки трейсинга аккаунта; подробнее в [политике хранения данных Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/security/data-storage). История этой беседы с разработчиком автоматически в Telegram не переносится.

## Когда приходят уведомления

Процесс бота должен работать, а компьютер — быть включённым и подключённым к интернету. Если компьютер спит или бот остановлен, отправка невозможна. После запуска бот проверит пропущенные напоминания и отправит просроченные. Для регулярного дела придёт одно пропущенное уведомление, после чего расписание перейдёт к ближайшему будущему повтору. Для работы круглосуточно проект можно разместить на постоянно работающем компьютере или сервере.

Доставка устроена с повторными попытками. При редком сбое между успешной отправкой и записью результата в базу одно уведомление может прийти повторно. Ежедневная сводка проверяется периодически, поэтому возможна небольшая задержка относительно выбранного времени.

## Данные и резервные копии

- Библиотека, рабочие разделы и материалы, поиск, категории, избранное, напоминания, настройки, статистика, экспорт и действия кнопок ограничены данными текущего пользователя. Другие пользователи бота не получают к ним доступ.
- Напоминания, тексты, карточки и настройки всех пользователей находятся в SQLite-базе на компьютере или сервере оператора, по умолчанию `data/assistant.sqlite3`. Каждая запись привязана к Telegram ID своего пользователя.
- Для вложений сохраняются Telegram file ID и метаданные; бот возвращает оригинал через Telegram. При запуске распознавания файл временно скачивается в память процесса. Подтверждённый текст, черновик распознавания и версии хранятся в SQLite. Полноценной локальной копии оригинала нет.
- `/export` отдаёт пользователю JSON только с его текстами и метаданными. Это **не резервная копия содержимого файлов** и не команда восстановления базы.
- Оператор может сделать резервную копию: остановить бота и скопировать всю папку `data` в безопасное место. Такая копия содержит данные всех пользователей. Для восстановления замените её сохранённой копией при остановленном боте. Если изменили `DATABASE_PATH`, копируйте папку с указанной базой.
- `.env`, база и окружение исключены из Git. Токен хранится только в локальном `.env` оператора; пользователям не передают ни токен, ни базу. Храните резервные копии приватно; `.env` нужен отдельно от базы для повторного запуска.

Это изоляция данных **между пользователями бота**, а не сквозное шифрование от оператора: человек с доступом к серверу, SQLite-базе или резервным копиям может прочитать хранящиеся данные. Общение проходит через Telegram; бот не обеспечивает анонимность или секретность переписки от Telegram.
