# Интерфейс без лишних сообщений · 3.3

Основной интерфейс — одна обновляемая панель с inline-кнопками. Меню, карточки, мастера ввода, ответы ИИ и результаты распознавания используют её. Номер панели хранится отдельно для каждого пользователя в SQLite. Длинные тексты листаются внутри панели; кнопки страниц работают до перехода в другой экран или перезапуска.

`/start` переносит панель вниз чата и удаляет прежнюю отслеживаемую панель. Если Telegram запретил удаление, прежняя панель остаётся. Если панель удалили вручную, следующее действие создаст новую. Сетевая ошибка не создаёт дубликат.

Обычное взаимодействие: одна панель бота + последнее текстовое сообщение пользователя. Предыдущий текст ставится на удаление после следующего обработанного сообщения. Новые вложения удаляются из входящей истории только после сохранения записи материала и проверенной локальной копии файла. Запрошенные файлы/экспорты остаются на час, затем удаляются из чата, сохраняя материал в боте. Очередь удаления переживает перезапуск. Ограничения, хранение и резервирование описаны в [AUTO_INBOX.md](AUTO_INBOX.md).

Напоминание или сводка создаёт новую панель внизу чата для уведомления и удаляет предыдущую. Последнее уведомление показано над текущим экраном с кнопками. Ввод не сбрасывается, завершение работающего ИИ-запроса обновляет новую панель. Если одновременно пришло несколько уведомлений, в панели остаётся последнее; все напоминания доступны в их разделе.

Фоновая обработка не заменяет экран, если пользователь перешёл в другой раздел. Результат авторазбора остаётся в карточке материала. Новые сообщения в уже работающем ИИ-диалоге просят дождаться ответа, не отменяя его.

Telegram не даёт удалять сообщения старше 48 часов. Старую неотслеживаемую историю бот не очищает. Неудавшееся скачивание оставляет входящий файл; запрошенные вложения на час увеличивают число сообщений. Поэтому абсолютное ограничение ровно двумя сообщениями при всех обстоятельствах невозможно обещать.

Это интерфейс внутри чата, не Mini App. Для Telegram Mini App нужен публичный HTTPS-интерфейс и серверный API с проверкой Telegram initData. Хостинг и Mini App в этом выпуске не подключены.
